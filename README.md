# Vinyl Spin — Маркетплейс виниловых пластинок

**Внимание:** Этот сайт создан исключительно в учебных целях и в качестве демонстрации навыков веб-разработки (дизайн-концепт). Сайт не является реальным интернет-магазином и не собирает платежные данные. Все изображения взяты из открытых источников в ознакомительных целях.

### Использованный стек технологий:
* HTML5 (Семантическая вёрстка по методологии БЭМ)
* CSS3 (Flexbox, Grid, CSS-анимация вращения пластинок)
* JavaScript (Интерактивный таймер обратного отсчета для аукциона)
